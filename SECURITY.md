# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **TimeSync Pro**, please report it responsibly.

### How to Report
- Email me directly at: **ehsanmansouri128@mail.com**
- Subject line: `[Security] TimeSync Pro Vulnerability`
- Include:
  - A clear description of the issue
  - Steps to reproduce
  - Potential impact
  - Suggested fix (if any)

### What to Expect
- I will acknowledge your report within **48 hours**
- I will work to verify and address the issue promptly
- You will be credited (with your permission) if a fix is released

> ⚠️ **Do not** disclose vulnerabilities publicly until a fix is available.

Thank you for helping keep TimeSync Pro secure!
